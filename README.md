# Smart Study Planner

A responsive student productivity app built with **HTML, CSS, and vanilla JavaScript**. Organize study tasks, set due dates, track completion, and use a built-in Pomodoro timer.

## Features

- Add study tasks with a subject, due date, time, and priority
- Edit, complete, and delete tasks
- Filter tasks by all, to-do, and completed
- Progress summary with total, completed, remaining, and percentage
- 25-minute focus / 5-minute break Pomodoro timer
- Rotating study tips
- Saves tasks in browser `localStorage`
- Responsive layout for desktop and mobile

## Files

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — task management, local storage, and timer

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or build step is required.

## Publish on GitHub Pages

1. Create a GitHub repository named `smart-study-planner`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for deployment and open the Pages URL shown in settings.

## Note

Tasks are saved only in the current browser on the current device. This starter project does not include accounts or cloud syncing.
